# 额度窗口语义修正实施计划

## 任务一：完善后端额度摘要测试

1. 增加缺失 secondary 且 primary 为 10080 分钟的测试数据。
2. 断言窗口标签根据真实时长生成。
3. 断言缺失窗口不会生成 100% 占位项。
4. 覆盖未知分钟数的通用标签。

## 任务二：实现动态窗口转换

1. 调整 `_rate_limit`，只转换实际存在的窗口。
2. 根据 `windowDurationMins` 生成 `5h`、`Weekly` 或通用时长标签。
3. 保持百分比限制、重置时间和脱敏行为不变。

## 任务三：统一调度窗口与刷新容错

1. 增加统一的账号调度窗口选择函数。
2. 刷新频率和调度候选统一使用该函数。
3. 额度读取失败时设置 30 秒重试时间并保留最后成功快照。
4. 预计占比只纳入启用且可调度账号。
5. 补充对应账号池测试。

## 任务四：修正前端加载和动态标签

1. 账号摘要窗口优先选择真实 5 小时窗口，否则回退最短有效窗口。
2. OAuth 账号页和负载页使用窗口自带标签。
3. 多账号额度页面先读取账号快照，仅在无账号时请求单账号兼容接口。
4. 修正额度状态徽标样式和停用状态文案。
5. 补充真实周窗口和请求次数测试。

## 任务五：验证

1. 运行额度摘要、账号池和管理接口后端测试。
2. 运行前端 API、组件和样式测试。
3. 运行完整测试套件并检查工作区差异。
