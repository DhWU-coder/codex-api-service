# 账号自定义权重倍率

## 行为约定

每个真实账号持久化一个 `weight_multiplier`，默认为 1。最终调度权重为原自动权重乘以该倍率，Web 和 CLI 两种授权共享同一个账号设置。倍率支持自定义小数，不只限于预设选项。

为避免浮点上溢、下溢或非有限值破坏平滑轮询，允许范围为 0.000001 至 1000000（包含边界），只接受 JSON 数字，拒绝布尔值、空值、字符串、NaN 和无穷值。停用账号继续使用独立的启停按钮，不用零倍率代替。

## 数据与调度

- 旧注册表缺失该字段时读取为 1，损坏或越界值安全回退为 1。
- 账号重命名、启停、授权同步、调度模式切换、重启和旧名称补全都必须保留倍率。
- 管理接口使用 `weightMultiplier` 读写，保存后立即重建调度候选和预计占比。
- 只有可用且启用的账号参与普通加权调度，倍率不能绕过认证、限流、并发限制或绑定响应链。
- 用户改变倍率时清零平滑轮询累计分数，保留并发计数，防止旧累计分数延迟新倍率生效。

## 界面

账号卡片增加倍率展示及“权重设置”入口。弹窗提供自定义数字输入、少量快捷倍率和恢复默认操作，清晰说明实际占比仍受额度、套餐、并发和其他账号状态影响。兼容旧后端缺失字段时按 1 展示。
