# 连接端口页设计

## 已确认功能

侧栏新增“连接端口”页，以本地连接和局域网连接两组展示 IP、实际监听端口、API Base URL、控制台、健康检查及模型列表地址。每条地址均有复制按钮，提供成功或失败反馈；刷新按钮重新读取当前网络地址。

## 服务端数据

新增受现有管理鉴权保护的只读接口 `/admin/connections`。基于当前服务配置和服务电脑的出口网卡探测生成地址，不采用浏览器地址或客户端 Host 请求头。

通配 IPv4 监听时，本地地址用 127.0.0.1，局域网地址使用现有探测函数。仅回环监听时明确说明局域网未开放；探测失败时不生成可复制的错误地址。指定网卡监听时仅展示实际监听的接口，本地回环未监听则明确说明。IPv6 地址生成 URL 时加方括号；IPv6 通配监听无法确定局域网 IPv6 地址时显示未检测到，不猜测 IPv4 是否可用。

接口只返回非敏感连接信息，不改变监听配置、鉴权、账户和请求转发。

## 前端交互

页面进入及访问密钥变化时重新加载，刷新过程中显示读取状态并禁用刷新；失败显示错误并可重试。两组卡片在窄屏纵向排列，长地址可换行。

复制优先使用剪贴板 API；不可用或被拒绝时，在点击操作中尝试隐藏文本框复制，保留原焦点并清理临时元素。失败提示手动选择地址复制，不虚报成功。API Base URL 明确用于第三方配置，浏览器页面使用控制台地址。

## 验证

覆盖真实端口、通配与回环监听、特定网卡、IPv6、探测失败、刷新 IP 变化及管理鉴权；前端覆盖地址渲染、导航、刷新、加载失败、复制成功、HTTP 回退及复制失败。运行后端及前端测试、生产构建，服务空闲时重启验证接口和新静态资源，随后仅提交本次变更并推送。
