# OAuth 账号卡片额度窗口切换

## 已确认规则

OAuth 账号卡片同时存在真实 5 小时和每周额度窗口时，每周剩余为 0 则优先展示 Weekly，否则展示 5h。剩余比例、重置时间、进度条及其标签必须来自同一个窗口。每周剩余小于 0 也按耗尽处理。

按实际窗口时长识别 5h（18000 秒）和 Weekly（604800 秒），不依赖数组顺序或 primary、secondary 位置。只有一个窗口时展示该窗口，缺失窗口时沿用原有占位，不补造额度。

## 范围

仅调整 OAuth 账号卡片摘要的窗口选择。详情抽屉仍展示全部真实窗口，账户并发负载页保持原有摘要规则，后端额度读取及调度保持现状。

## 验证

验证周额度耗尽但 5h 充足、双窗口均耗尽、周额度未耗尽但 5h 为 0、单窗口及刷新后的双向切换；确认重置时间和进度条随标签同步，详情抽屉仍展示两个窗口。
